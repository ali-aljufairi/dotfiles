# personal-linux

Linux-host-specific notes and overrides for the shared dotfiles repo.

## Recommended use

Keep portable config in `home/` first. Use this directory only for Linux-host-specific concerns, such as:

- machine-specific package notes
- display/output quirks
- local services or timers
- hardware-specific tweaks

## Current host notes

This machine is the primary migration source and currently uses Arch Linux with Fish, Ghostty, Atuin, and the shared Neovim config.
