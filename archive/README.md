# archive

This directory holds legacy config sources kept for safe migration reference.

## Rules

- Do **not** treat these directories as the active source of truth.
- Do **not** make new day-to-day edits here.
- If something valuable is found, copy it into `home/`, `hosts/`, `os/`, or `docs/` and then leave the archive untouched.

- `upstream-dotfiles-hidden`
